# Atmosfer Akademisi

İTÜ meteoroloji dersleri için etkileşimli çalışma alanı. Yayın: https://akinci22.github.io/atmosfer-akademisi/

- `akademi/` — Atmosfer Akademisi uygulaması: müfredat haritası, konular, ders kartları, laboratuvar (simülasyon, kavram, ispat, 3B, dikey kesit, denklem), ansiklopedi, kod atölyesi, havacılık, kaynaklar, canlı atmosfer, kariyer (ayrı depoda derlenir, `vite build` çıktısı)
- `harita-okulu/` — MTO 302E Hava Analizi ve Öngörü (ayrı depoda derlenir, `node tools/paketle.mjs` çıktısı)
- `sinoptik-brifing/`, `brifing-ornegi/`, `hava-analizi-proje-rehberi/` — MTO 302E
- `bulut-fizigi-rehberi/` — MTO 229E · `hec-hms/`, `hidrometeoroloji-quiz/` — MTO 316 · `cfd-temelleri/` — MTO 303E
